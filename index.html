成本計算機使用教學

  1. 選料理點開選單瀏覽所有料理，或輸入名稱搜尋；最上方可建立「＋自訂料理」。
  2. 調整材料修改每份用量與單價，或新增材料。同名材料的單價會同步套用至所有料理。
  3. 比較結果按「＋ 新增料理」加入比較，查看每份成本與 1～5 星利潤。
計算與保存須知

每份成本＝各材料的用量 × 單價加總；利潤＝該星級售價 − 每份成本。

未設定的材料單價目前以 0 金幣計算，請先確認價格。自訂料理可試算材料成本，尚無星級售價，利潤會顯示「待補」。

試算調整僅保留於本次開啟頁面；重新整理後會重設，不包含在圖鑑 JSON 備份中。

記錄五星與花色
  1. 選擇圖鑑分類，再依名稱、地點或食材搜尋。
  2. 取得五星後，勾選該項目，首頁會同步顯示收藏進度。
  3. 花卉可展開逐一勾選花色；勾選花名前的方框會全選，取消則全部取消。收齊全部花色才算完成，作物按每種五星記錄。
篩選條件與出沒時間
  • 初始條件：10 級及以下、全部收錄類型、晴天與開啟時的本機時段。每次開啟時收錄類型預設全選，其餘條件記住上次選擇。
  • 等級：包含所選等級以下的項目；未知等級請選「不限等級」。
  • 清除其他篩選：清除目前分類的搜尋及其他篩選，保留天氣與時段。「重設預設條件」恢復初始設定。
  • 天氣與時段：魚、蟲、鳥共用這兩項條件。時間不會自動跟著時鐘切換，可按「切換到現在時段」手動更新。
  • 鳥類五星：「僅五星」使用五星條件篩選，與一般出沒資訊分開顯示。篩選結果不保證遊戲即時出沒，待確認資訊請以遊戲實際情況為準。
排序與料理利潤
  • 烹飪與成本計算機的料理選單預設依編號由小到大排列；烹飪列表可按「編號排序」恢復此順序。其他分類依日常、當前活動、過往活動分組。手動切換排序後，以所選欄位為主。
  • 點選名稱、等級、地點等可排序的欄位標題，再點一次可切換排序方向。
  • 料理可選 1～5 星查看利潤；展開詳情可查看成本、售價與食材。
  • 利潤依來源資料計算，不計時間與食材轉售的機會成本；未知數值排在後方。
成本計算機：選料理、改材料、比成本
  1. 從側邊選單進入「成本計算機」。料理下拉選單可瀏覽全部料理，也可輸入名稱搜尋。
  2. 選單最上方的「＋自訂料理」可建立空白料理；輸入名稱後也可用該名稱建立。
  3. 調整每份用量與單價，或輸入材料名稱後按「加入」。修改同名材料單價會同步影響所有比較中的料理。
  4. 按「＋ 新增料理」加入其他料理，可比較最多六道。選擇兩道以上時，下方顯示成本與各星級利潤比較表。

計算：每份成本＝各材料（用量 × 單價）加總；每份利潤＝對應星級售價 − 每份成本。

價格：未設定的材料單價目前預設為 0 金幣，請自行確認並調整。「限時材料」表示材料取得受限，不代表料理停止製作。

自訂料理：可試算材料成本；目前尚無星級售價，利潤顯示「待補」。

保存：試算調整僅保留於本次開啟頁面，重新整理後重設；圖鑑 JSON 備份不包含這些調整。

備份、還原與換裝置
  1. 按「匯出備份」，確認 JSON 檔案已下載並保存。
  2. 換裝置、換瀏覽器或從本機檔案移到網站時，在新位置按「匯入進度」，選取備份檔。
  3. 「合併進度」保留雙方已完成項目與目前篩選；「取代目前進度」使用備份的勾選與篩選，操作前請先備份。

收藏進度只保存在目前瀏覽器，不會上傳或跨裝置同步。清除網站資料、更換網址或瀏覽器，可能無法讀取原進度。

首次累積 10 筆收集，或與上次匯出相比有 10 筆變更時，系統會提醒備份；保存紀錄不代表檔案已下載成功。

舊版備份：可匯入相容的舊版 JSON；有兩份進度時可依序合併。舊版花色紀錄會對應至可見花色，無法對應的項目會在匯入前提示，原始備份檔不受影響。
